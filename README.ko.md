# 튜브그로스 — 유튜버 성장 마케팅 에이전시 (데모)

**편집·썸네일·기획·마케팅**으로 성장을 꿈꾸는 유튜버를 돕는 가상의 에이전시 웹앱입니다.
빌드 과정이 없는 정적 사이트이며, 실제로 작동하는 **규칙 기반 채널 진단 엔진**과
**견적 계산기**를 포함합니다.

> **English docs: [README.md](./README.md)**

**라이브 데모: https://clsoftlab-lang.github.io/youtuber-growth-agency/**

## 무엇인가요
- 가격·기간이 있는 서비스 패키지(편집 / 썸네일 / 기획 / 마케팅).
- 카테고리로 필터링되는 가상의 성장 사례 포트폴리오.
- **채널 진단 도구** — 구독자 수, 평균 조회수, 업로드 주기, 주제, 운영 개월수를 입력하면
  성장 점수(0~100), 지표별 막대, 개선 제안, 추천 패키지를 즉시 계산합니다. 순수 규칙 기반
  엔진으로 브라우저에서 완전히 동작합니다.
- **의뢰 & 견적 흐름** — 패키지 + 추가 옵션 + 계약 기간 선택 → 자동 견적 → 상담 신청 →
  진행 상태 관리(접수 → 상담중 → 진행중 → 완료).
- 전문 분야·평점으로 필터링하는 편집자/전문가 매칭.
- "내 의뢰"와 고객 후기.

## 로컬 실행
빌드도 의존성도 없습니다. ES 모듈을 쓰므로 HTTP로 서빙해야 합니다.

```bash
python -m http.server 9006
# http://localhost:9006 접속
```

또는 Node로: `npx serve .`

## 검증
```bash
node check.mjs      # JSON 파싱 + 모든 JS node --check + HTML 컨테이너 + 단위 테스트
```

## 기능
| 영역 | 내용 |
| --- | --- |
| 진단 | 순수 `diagnostic.js`: 참여율(0~30), 업로드 주기(0~25), 잠재력(0~20), 주제(0~25) |
| 견적 | 순수 `quote.js`: 기본가 × 개월 + 애드온 − 장기 할인 + 긴급 할증 |
| 데이터 | 포트폴리오 12 + 전문가 12 + 패키지 3 + 애드온 5 + 후기 8 (`data/*.json`) |
| 상태 | 의뢰는 `localStorage`에 저장(try/catch 보호, 초기화 가능) |
| UI | 반응형·모바일 우선, `prefers-color-scheme` 라이트/다크, 한국어, 인라인 SVG만 사용 |

## 진단 엔진 동작 방식
`diagnose(input)`은 독립적인 4개 부분 점수를 합산합니다.
1. **참여율** — 평균 조회수 ÷ 구독자, 비율 1.0에서 상한 → 최대 30점.
2. **업로드 주기** — 일 단위 구간화(≤3일 최고, >30일 최저) → 최대 25점.
3. **잠재력** — 작은 채널일수록 높은 점수(성장 여지) + 성장 모멘텀 가점 → 최대 20점.
4. **주제** — 니치별 수요·수익화 테이블 조회, 미분류 주제는 중간값 → 최대 25점.

합계(0~100)는 등급(A~E), 맞춤 제안, 추천 패키지로 매핑됩니다.

## 견적 엔진 동작 방식
`calcQuote({ pkg, addonCatalog, selectedAddons, months, rush })`:
`기본가 = pkg.priceMonthly × 개월수`에 수량 기반 애드온을 더해 소계를 만들고,
장기 할인(3개월 5%, 6개월 10%, 12개월+ 15%)을 뺀 뒤, 선택 시 긴급 할증(+30%)을
할인 후 금액에 적용해 총액을 산출합니다.

## 🤖 AI 기능 (API 연동)

세 가지 AI 기능이 추가되었습니다 (모두 앱의 진단/견적 엔진과 패키지·전문가 데이터를 재사용):

1. **AI 채널 성장 상담 챗봇** — 채널 진단 결과 기반 맞춤 조언.
2. **콘텐츠 기획/제목·썸네일 아이디어 생성**.
3. **견적/패키지 추천 설명**.

**데모 = 목업(mock).** 기본값에서 `ai/config.js` 의 `AI_ENDPOINT` 가 비어 있으며,
브라우저에서 결정적 한국어 MockProvider가 즉시 응답합니다. 키·서버·네트워크가 필요 없습니다.

**실제 AI 활성화.** 백엔드 프록시로 전환합니다.

```bash
cd server
npm install                       # @anthropic-ai/sdk
cp .env.example .env              # .env 에 ANTHROPIC_API_KEY 입력 (커밋 금지)
node --env-file=.env index.mjs    # http://localhost:8787/api/ai
```

그런 다음 `ai/config.js` 를 수정합니다.

```js
export const AI_ENDPOINT = "http://localhost:8787/api/ai";
```

- 모델: **`claude-opus-5`** (adaptive thinking), 응답은 텍스트 스트리밍.
- 서버는 `data/*.json` 카탈로그를 로드해 프롬프트에 grounding.
- **굵게: API 키는 서버 측에만 둡니다. 브라우저·프런트엔드 코드·리포지토리에는 절대 키를 넣지 않습니다.** `.env` 는 `.gitignore` 로 제외됩니다.

자세한 내용: [`server/README.md`](./server/README.md). 검증: `node check.mjs` 가 `ai/`·`server/` 문법, `AI_ENDPOINT` 공백, 실제 키 형식 노출을 함께 점검합니다.

## 데모 모드 경계
**본 프로젝트는 시연용 빌드입니다. 구체적으로:**
- **모든 데이터는 가상입니다**(채널·전문가·후기·가격) — 실존 인물이나 브랜드가 아닙니다.
- **진단은 규칙 기반이며 실제 분석이 아닙니다** — YouTube에 연결되지 않습니다.
- **견적과 의뢰는 모의입니다** — 청구·계약·결제가 발생하지 않습니다.
- **상태는 브라우저 localStorage에만 저장되며 실제 데이터베이스가 아닙니다** — 공유·동기화되지 않습니다.
- **계정·로그인·개인정보(PII) 수집이 없습니다.**
- 실제 상용 빌드라면 백엔드, 실제 YouTube Data API 분석, 결제, 인증이 추가됩니다.
